# Catalyst Mod Kit

An unofficial pocket guide for community members and moderators in the [Catalyst](https://catalyst.app) Discord. Written in Indonesian, with English replies you can copy straight into Discord.

**Live:** https://catalyst-mod-kit.vercel.app

## What's inside

- **Inti**: Catalyst explained in 30 seconds (ID + EN)
- **Visi & Misi**: vision, mission and goals, quoted directly from the founders, Sequoia and the official FAQ
- **Produk**: the intent → workflow → approve → strategy → close-out flow, the official features, and deposits, fees and safety
- **FAQ salin**: 10 common questions, each with an English reply and a copy button
- **Channel**: playbooks and copyable templates for #trade-ideas, #general and #feedback
- **Jalur Mod**: practical steps toward a Regional Moderator role
- **Tim, Glosarium, Sumber**: team, investors, timeline, terms and source links

It is a single static `index.html` with no build step. It works offline, supports light and dark mode, and is designed for phone screens.

## Run locally

Open `index.html` in a browser, or:

```bash
npx serve .
```
